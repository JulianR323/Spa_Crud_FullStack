# Cliente del Spa App

Frontend React creado con Vite.

## Iniciar

Desde esta carpeta:

```powershell
npm install
npm run dev
```

Vite ejecuta el sitio en `http://localhost:5173` y reenvía las solicitudes `/api` a FastAPI en `http://localhost:8000`.

## Comprobar

```powershell
npm run lint
npm run build
```
